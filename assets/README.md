# 풀잎 이미지 에셋 안내

## 규칙 (이 규칙만 지키면 파일을 넣는 즉시 자동 적용됩니다)

| 항목 | 규칙 |
|---|---|
| 위치 | `assets/blades/` |
| 파일명 | `<카테고리>_<번호>.png` — 카테고리는 `sprout`(새싹) / `grass`(풀) / `weed`(작은 잡초) |
| 형식 | PNG, **투명 배경(RGBA)** |
| 기준점 | **풀뿌리가 이미지 아래쪽 가운데**에 오도록 (이미지 맨 아래에 뿌리가 닿게) |
| 크기 | 풀 128×256, 새싹 96×128, 잡초 128×160 권장 (세로 256px 초과는 자동 축소) |
| 개수 | 카테고리당 4~8장 이상 권장 (많을수록 반복감 감소) |
| 색 | 중간 톤의 초록. 밝기/색조는 프로그램이 풀잎마다 21단계로 조절함 |

카테고리에 파일이 1장이라도 있으면 그 카테고리는 **내 파일만** 쓰고, 하나도 없으면 임시 그래픽(코드로 그림)을 씁니다.
현재 `assets/blades/` 에는 임시 그래픽을 PNG 로 저장한 14장이 들어 있습니다(`tools/make_placeholder_assets.py`).
진짜 이미지로 바꾸려면 같은 이름으로 덮어쓰거나, 임시 파일을 지우고 새 파일을 넣으세요.
확인: `python -m typegrass assets`

## 권장 파일 목록

| 파일 | 내용 |
|---|---|
| sprout_01 ~ sprout_04 | 막 올라온 새싹: 떡잎 한 쌍 / 짧은 풀 2~3가닥 / 구부러진 싹 / 작은 잎 달린 싹 |
| grass_01 ~ grass_06 | 잔디·풀잎 한 가닥. 곧은 것, 왼쪽/오른쪽으로 휜 것, 폭이 넓은 것, 가는 것 섞기 |
| weed_01 ~ weed_04 | 토끼풀(클로버) 잎 / 질경이류 넓은 잎 / 민들레류 톱니 잎 / 작은 들꽃 한 송이 |

## 만드는 방법 (사실적인 이미지)

1. **직접 촬영** (저작권이 가장 안전): 잔디밭에서 풀 한 가닥(또는 한 포기)을 흰 종이/하늘을 배경으로 접사 촬영.
2. **배경 제거**: 맥 '미리보기'의 *도구 > 배경 제거*, Keynote/Pages 의 *즉석 알파*, 또는 remove.bg 같은 서비스.
   가장자리의 흰 테두리가 남으면 지우개로 정리.
3. **자르고 맞추기**: 풀뿌리가 아래쪽 가운데에 오도록 캔버스를 맞추고 PNG(투명 유지)로 내보내기.
4. 한 가닥씩, 모양이 서로 다른 것을 여러 장 만든다 (같은 사진을 반복하면 티가 남).

## 저작권 / 사용 허가 (꼭 확인)

* **내가 직접 찍거나 그린 이미지**: 문제 없음.
* **CC0 / 퍼블릭 도메인**으로 명시된 이미지: 상업적 이용·수정 가능. 각 이미지 페이지에서 라이선스 문구를 직접 확인.
* **피해야 할 것**: 구글 이미지 검색 결과, "개인 사용만 허용", CC BY-NC(비상업), 출처 표기 필수인데 표기하지 않는 경우,
  재배포 금지(앱에 포함해 공개 배포 불가) 조건의 이미지.
* AI 생성 이미지는 서비스별 약관(상업 이용·재배포 가능 여부)을 확인.
* 가져온 이미지는 아래 `LICENSES.md` 에 **파일명 / 출처 URL / 라이선스 / 확인 날짜**를 기록해 두세요.
* 나만 쓰는 용도와, 앱을 남에게 배포·판매하는 용도는 허용 범위가 다릅니다. 배포 계획이 있으면 CC0 또는 직접 제작만 쓰는 것이 안전합니다.
